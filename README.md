# DSA Playground

**DSA Playground** is a C++ project where I have implemented various **Data Structures** and **Algorithms** from scratch. The goal of this project is to provide a deeper understanding of fundamental computer science concepts by manually coding data structures and algorithms without relying on any external libraries.

## Introduction
This project showcases my personal implementations of popular data structures and algorithms in C++. It’s designed as a playground for experimenting with and understanding core concepts of data structures and algorithms, all built from scratch.

## Implemented Data Structures
Here are the data structures I have implemented:
- **Linked List**: A basic implementation of singly linked lists.
- **Stack**: A stack data structure using arrays or linked lists.
- **Queue**: A queue data structure implemented using arrays or linked lists.
- **Graph**: An adjacency list-based graph implementation supporting both directed and undirected graphs.

## Implemented Algorithms
The following algorithms are implemented to show their inner workings:
- **Sorting Algorithms**:
  - Bubble Sort
  - Quick Sort
- **Searching Algorithms**:
  - Binary Search

## Installation

To set up and build the project, follow these steps:

1. Clone the repository:

    ```bash
    git clone https://github.com/Guwanch1/dsa_playground.git
    cd dsa_playground
    ```

2. Build the project using `Makefile`:

    ```bash
    make
    ```

This will compile the project and generate an executable file named `main`.

## Usage

After building the project, you can run the program with:

```bash
./main
